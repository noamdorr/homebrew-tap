# QuotaCanary Homebrew tap

Install with `brew install --cask noamdorr/tap/quotacanary`. Requires macOS 26 or later. The app updates itself. `brew uninstall --cask --zap noamdorr/tap/quotacanary` also removes local settings and reading history. API keys stay in your login Keychain until you use the erase option in the app's Settings.
